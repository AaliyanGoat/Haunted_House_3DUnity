 About the Game

Haunted House is a 3D horror game developed in Unity where the player explores a haunted house, solves puzzles, avoids supernatural threats, and searches for a way to escape. 
The game focuses on creating a tense atmosphere through lighting, sound effects, and exploration.

 Why I Made This Game

I created this project to improve my Unity game development skills and gain practical experience with 3D game design.
The project helped me learn how different game systems work together, such as player movement, enemy AI, UI, animations, lighting, and scene management. 
It also strengthened my programming skills in C#.
